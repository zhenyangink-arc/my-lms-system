## A类：骨骼关节区域（6个）

### A1. Shoulder 肩部（SHOULDER_L / SHOULDER_R）

- **当前状态**：**唯一已有可用中间产物的区域**——`AHAN_ManualRetopoPrep_v01`里这块区域不是原始IM15K网格，而是A1 Pilot阶段做过"mirrored bisect环切 + 局部Laplacian平滑"的`Functional Provisional`版本：技术零缺陷、权重零泄漏、HandsUp/Combing_PreTest（60°）功能测试通过，但**肩窝边界仍有锯齿、局部尖角、曲率不连续**，官方结论是"技术+功能可用，但不是教科书级Edge Flow"（详见[AHAN_SHOULDER_TRUE_LOCAL_RETOPO_REPORT.md](AHAN_SHOULDER_TRUE_LOCAL_RETOPO_REPORT.md)记录的4次失败的自动缝合尝试）。
- **删除范围**：以肩关节坐标 SHOULDER_L=(0.25,0,0.60) / SHOULDER_R=(-0.25,0,0.60) 为中心，沿手臂方向覆盖上臂根部到肩窝，沿躯干方向覆盖到马甲肩带宽度（对应Vertex Group权重范围：内径0.05m全权重，外径0.14m零权重）。**建议直接删除现有Provisional版本在此区域的全部面片**（不要在已经Smooth过的基础上继续加线，Smooth产生的走线不是可参照的Edge Flow基础）。
- **推荐Edge Loop走向**：围绕上臂截面闭合成环（垂直于手臂长轴），肩窝腋下位置的环需要局部凹陷过渡，不能让边线平直穿过腋下（60°抬升时会在腋下产生尖锐折角）。
- **建议Loop数量**：3圈——肩关节主环（0.60m处）+ 上方靠近躯干的过渡环 + 下方靠近上臂的过渡环。过渡带宽度建议覆盖上臂直径的0.8-1倍（60°是全部区域里最大转动角，过渡带必须够宽）。
- **Pole应放在哪里**：肩窝腋下靠后位置（正面/常见视角不显眼的角度），预计需要2-3个三角面/五边面过渡点——这是行业内肩部拓扑的常见做法，不是缺陷。
- **如何接回IM15K主体**：肩部环外圈辐条对齐周围现有的斜向网格线，必要时局部微调周围1-2圈网格走向。马甲肩带的可见轮廓线（布料边缘）一个顶点都不能动，只调整边缘内侧走线。
- **Shrinkwrap目标**：先用`2A-base/ahan_2A_clean_base.obj`粗投射一次，再单独针对腋下凹陷区域用原始500K高模（`AHAN_Hunyuan_Master_500K.glb`，只读）做一次局部精细投射，顺手复查审计报告P1-1提到的腋下接缝问题。
- **对应压力测试动作**：`AHAN_Combing_PreTest`（60°，全部动作最大值）+ `AHAN_HandsUp`（双臂同时60°，检查左右对称）。
- **FINAL PASS标准**：技术零缺陷（0非流形/0自相交/单连通）+ 权重零泄漏（腹部/马甲关键点位移0）+ 60°测试下腋下曲率连续、无锯齿、无尖角、无"团块插接"观感 + 马甲轮廓线未移动 + 左右对称 + **肩窝Edge Flow本身能在近景Clay渲染下经受住"是否像教科书级手工重拓扑"的视觉检验**（这是Provisional版本明确未达到的一条，也是本区域FINAL PASS与此前所有阶段结论的唯一区别）。

### A2. Elbow 肘部（ELBOW_L / ELBOW_R）

- **当前状态**：本session实测确认——肘关节坐标(0.305,-0.005,0.46)周围射线截面规律性差（CV 0.23-0.6，命中率48-67%），近景渲染（`elbow_area_front.png`等，见session早期记录）直接显示前臂在这个位置已完全视觉融入浑圆腹部，**没有任何独立于腹部的自由边界**。
- **删除范围**：以ELBOW_L=(0.305,-0.005,0.46)为中心，上下各覆盖前臂/上臂长度的三分之一左右（Vertex Group：内径0.03m/外径0.09m）。**这个范围目前整体都是躯干主体的一部分，删除后不是"挖一个洞接回一圈手臂"，而是需要操作者先目视判断"手臂应该从哪里开始独立出来"，可能需要比这个半径更大的范围来重新雕出一段独立的前臂几何，再在其上建环**——这是本区域和A1肩部最大的不同：肩部至少有部分几何已经独立成手臂形状，肘部这里连几何本身都还粘连在腹部里。
- **推荐Edge Loop走向**：围绕前臂截面闭合成环，弯曲内侧（挤压侧）边线适当加密，避免48°弯曲时内侧穿模挤压。
- **建议Loop数量**：3圈（肘关节主环+上下各一圈过渡环）。过渡带宽度中等（48°弯曲量在6个关节区域里排第二）。
- **Pole应放在哪里**：预计前臂本身是相对简单的圆柱状区域，与周围网格密度差异不大，如果能雕出干净的独立几何，理论上不需要额外三角面过渡，直接对齐环数缝合；但如果最终仍需要过渡面，建议放在前臂内侧不显眼的位置。
- **如何接回IM15K主体**：由于本区域现状是"肉粘连"而非"边界缺口"，接回方式高度依赖操作者手工雕出的中间几何形态，无法预先给出确定性方案，建议先用Poly Build在高模参照下手动画出前臂应有的独立轮廓，再据此环切。
- **Shrinkwrap目标**：`2A-base`即可满足精度需求。
- **对应压力测试动作**：`AHAN_Combing_PreTest`（48°，全部动作最大值）+ `AHAN_Thinking`（38°，常规使用范围）。
- **FINAL PASS标准**：技术零缺陷 + 权重不牵动手腕以外区域/不牵动腹部 + 48°测试下内侧压缩自然、外侧拉伸平滑、无尖坑、无折断、无明显体积丢失 + 从侧面看手臂弧度不因加环而变直/变粗 + 左右对称。

### A3. Wrist 腕部（WRIST_L / WRIST_R）

- **当前状态**：与肘部同一根本原因，本session近景渲染（`wrist_area_front.png`）确认拳套手直接从腹部表面"长出来"，无自由悬空截面。此前方案文档曾把腕部位置误判在58%高度，已用rig-v01真实数据修正为31%高度（(±0.335,-0.03,0.34)）。
- **删除范围**：以WRIST_L=(0.335,-0.03,0.34)为中心，覆盖前臂末端到拳套手根部的过渡段（Vertex Group：内径0.025m/外径0.07m）。与肘部同理，这不是"接回一圈"而是需要先雕出独立几何。
- **推荐Edge Loop走向**：围绕手腕截面闭合成环。拳套手本身不做张合（决策：保留拳套手不加真人五指），腕部环只需支持手腕整体旋转+梳头动作的复合翻转，不需要为手指分支预留额外拓扑。
- **建议Loop数量**：3圈（腕关节主环+前臂侧过渡环+手掌侧过渡环）。43°角度不小且`AHAN_Combing_PreTest`包含复合轴翻转，过渡带建议比肘部略宽，确保手掌根部贴合，避免翻转时出现visible转折棱角。
- **Pole应放在哪里**：手掌是相对独立的"团子"造型，与前臂网格密度可能不完全匹配，缝合处预计需要1-2个过渡面，建议放在手掌内侧（贴近身体一侧）不显眼的位置。
- **如何接回IM15K主体**：同肘部，需要先手工雕出独立几何再环切，无法预先给出确定性方案。
- **Shrinkwrap目标**：`2A-base`即可。
- **对应压力测试动作**：`AHAN_Combing_PreTest`（43°，唯一包含手腕复合翻转的动作，全部动作最大值）+ `AHAN_Wave_Left/Right`（36°，常规摆手场景）。
- **FINAL PASS标准**：技术零缺陷 + 权重不扩散到前臂以外 + 43°+翻转测试下手掌与前臂过渡自然、无转折棱角 + 拳套手三瓣圆润轮廓不变 + 左右对称。

### A4. Hip 功能髋部（HIP_L / HIP_R，非解剖学结构）

- **当前状态**：本session近景渲染（`hip_full_front.png`）确认躯干下部直接鼓成两只极短爪状腿，腹部与腿之间**没有任何独立的髋部/大腿圆柱截面或过渡颈缩区**，比肘/腕更彻底（连"手臂至少有独立造型"这一级别都不存在）。
- **删除范围**：以HIP_L=(0.11,0.02,0.28)为中心，覆盖大腿根部到躯干下部的过渡带（Vertex Group：内径0.04m/外径0.11m）。**这里没有真实裆部凹陷可以参照，重建时边线走向必须顺着浑圆躯干本身的自然曲率，严禁人为雕出解剖学意义上的胯部凹陷**——那样会破坏Design Lock的整体比例，戳穿"没有裆部结构"这个既有造型特征。这是全部13个区域里最容易"手滑做过头"的一处。
- **推荐Edge Loop走向**：围绕大腿根部截面闭合成环，环的上半部分平滑融入浑圆躯干下部，不能留下明显"分界线"痕迹。
- **建议Loop数量**：3圈（髋关节功能环+躯干侧过渡环+大腿侧过渡环）。30°角度适中，过渡带宽度中等。
- **Pole应放在哪里**：躯干下部到大腿的曲率变化本身比较平缓，预计不需要额外三角面过渡；如果需要，放在大腿内侧靠后位置。
- **如何接回IM15K主体**：外部可见的浑圆躯干轮廓线一个顶点都不能动，只调整表面以下的拓扑走线——这条比其他区域都更严格。
- **Shrinkwrap目标**：`2A-base`即可。
- **对应压力测试动作**：`AHAN_Walk_Test`（30°，全部动作最大值）+ `AHAN_Sit_Test`（25°，同时检查与膝部联动）。
- **FINAL PASS标准**：技术零缺陷 + 权重不扩散到腹部中央（左右两侧权重范围在身体中线附近须有清晰分界，不能互相渗透混合，这是历史教训——见rig-v01旧蒙皮HandsUp腹部异常拉宽问题）+ 外部轮廓一个顶点未变 + 30°测试下无解剖学胯部凹陷被意外雕出 + 左右对称。

### A5. Knee 功能膝部（KNEE_L / KNEE_R，非解剖学结构）

- **当前状态**：本session最初被远景轮廓渲染误判为"清晰独立悬空的腿"，改用近景渲染（`knee_diag_front.png`/`knee_diag_wide.png`）后确认真相与髋部完全相同——浑圆躯干直接鼓出的短爪状凸起，没有独立圆柱形大腿/小腿过渡段。骨骼坐标(0.145,0,0.18)与最近实际网格顶点相距达0.117m（此前方案文档给出的坐标本身没有错，只是这个坐标点在当前网格上确实不贴合任何独立表面）。
- **删除范围**：以KNEE_L=(0.145,0,0.18)为中心，覆盖小腿上部到大腿下部的过渡带（Vertex Group：内径0.03m/外径0.09m）。与髋部同理，这不是加环而是需要先确定"腿应该在哪里独立出来"。
- **推荐Edge Loop走向**：围绕小腿截面闭合成环，考虑到`AHAN_Sit_Test`需要38°弯曲，膝盖前侧（弯曲挤压侧，朝向-Y方向）边线应比后侧略密。
- **建议Loop数量**：3圈。38°是下半身两个功能关节里角度较大的一个，过渡带建议比髋部稍宽。
- **Pole应放在哪里**：小腿预计是相对简单的圆柱区域，若能雕出独立几何应不需要额外过渡面；如果需要，放在小腿内侧。
- **如何接回IM15K主体**：短粗的腿部比例和脚掌衔接处的曲线不能变，这是外观关键特征。
- **Shrinkwrap目标**：`2A-base`即可。
- **对应压力测试动作**：`AHAN_Sit_Test`（38°，全部动作最大值）+ `AHAN_Walk_Test`/`AHAN_Step_Left/Right`（22-25°，常规行走范围）。
- **FINAL PASS标准**：技术零缺陷 + 权重不扩散到躯干主体 + 38°测试下前侧压缩自然、无穿模、无明显体积丢失 + 短粗腿部比例和脚掌衔接曲线未变 + 左右对称。

### A6. Neck 功能颈部（已FUNCTIONAL PASS，不在人工待办范围，此处仅作参照基准）

- **状态**：本session已完成，技术+权重+HeadLeft/Right(18°)+Nod(15°)+组合极限姿态(18°+18°)测试全部通过。存档于`retopo-v01/pilot-A6-neck/`。
- **唯一遗留瑕疵**：bisect与下巴/耳朵复杂几何相交产生269处三角扇（技术无缺陷，非教科书级纯quad），如后续做表情Shape Key时这些区域出现异常，可作为人工微调的候选点，不强制现在处理。
- **对其他区域的参考价值**：A6是本session唯一验证"当关节两侧存在真实独立几何（头部和躯干本就是连续但可分辨的两个体块）时，纯bisect环切也能做出功能性通过的结果"的区域——这为A1-A5未来的人工重拓扑提供了一个判断基准：**如果操作者手工雕出的独立几何本身质量足够好，后续环切+权重步骤可以复用A6/A1已验证的方法，不需要每个区域都重新发明形变验证流程。**

## B类：表情形变区域（2个，不按普通关节Edge Loop处理）

### B1. Eye 眼周（EYE_L / EYE_R）

- **当前状态**：IM15K自动打底的规则斜向四边面直接穿过眼球/眼眶区域，眼球和周围皮肤是同一套网格里连续的曲面，没有任何独立于皮肤的眼睑结构。
- **参考坐标**：EYE_L≈(0.166,-0.176,0.811)、EYE_R≈(-0.168,-0.175,0.809)（本session从当前网格眼眶区域顶点云质心实测得出，rig-v01没有对应骨骼，这两个坐标仅供人工定位参考中心，不是精确瞳孔中心）。
- **删除范围**：以上述坐标为中心，覆盖整个眼眶凹陷+眼球隆起区域（Vertex Group：内径0.02m/外径0.06m，供人工定位参考，实际删除边界应现场判断眼睑轮廓）。
- **推荐Edge Loop走向（不是普通关节环）**：围绕眼眶做**同心圆环状拓扑**（业内俗称"眼部拓扑环"，类似虹膜到眼眶的一圈圈同心边线），不能让边线直接从旁边平移穿过。同心环之间用放射状"辐条"边线连接到外围常规四边面网格。
- **建议Loop数量**：至少3圈同心环——最内圈贴眼睑边缘（未来眨眼Shape Key的关键控制线）、中间一圈在眼眶转折处、外圈作为向周围网格过渡的缓冲环。
- **Pole应放在哪里**：外圈同心环到周围常规网格之间因边数不对齐通常需要"辐条转三角"的过渡点（脸部拓扑标准做法，业内称"star/pole"），应放在不落在瞳孔正前方的位置（比如内外眼角侧）。
- **如何接回IM15K主体**：外圈辐条末端对齐周围现有斜向网格线，必要时局部微调周围1-2圈网格走向避免极端拉伸面。眼睛的大小、瞳孔位置、高光点位置、上扬眼型轮廓一个像素都不能变——这一步只是在现有眼睛表面下方重新组织拓扑，不是重新设计眼睛。
- **Shrinkwrap目标**：眼球是独立隆起曲面，投射时注意不要把同心环"压平"到眼眶皮肤上，建议对眼球和眼眶皮肤分开做投射校验。
- **对应压力测试**：**没有可用的rig-v01动作数据**（`AHAN_Blink`明确是占位动作，不产生眼睑形变，状态`FACIAL_RIG_PENDING`）。建议新拓扑完成后手动插入临时Shape Key（睁眼→半闭→全闭三档）验证同心环拓扑形变是否平滑、有无自相交，测试完删除，不算正式表情制作。
- **FINAL PASS标准**：技术零缺陷 + 同心环+辐条结构在临时Shape Key三档测试下无自相交、无非流形、过渡平滑 + 眼睛外观（大小/位置/高光/眼型轮廓）逐像素比对未变 + 左右对称。

### B2. Mouth 嘴周

- **当前状态**：同眼周，规则网格直接穿过嘴部区域，没有独立嘴部拓扑结构。
- **参考坐标**：MOUTH≈(0.002,-0.239,0.720)（本session从当前网格嘴唇区域顶点云质心实测得出）。
- **删除范围**：以上述坐标为中心，覆盖整个嘴部及周围脸颊过渡区（Vertex Group：内径0.02m/外径0.07m，供人工定位参考）。
- **推荐Edge Loop走向**：需要类似眼周的**环形+放射状"orbicularis oris"拓扑**（人脸拓扑标准做法：围绕嘴唇开合方向做环形边线，环外用辐条连接脸颊）——**不能只是在嘴的位置简单加一圈孤立环**，那样无法支撑开合、也无法支撑说话时嘴角上扬/下撇的口型变化。
- **建议Loop数量**：至少2-3圈环（贴嘴唇边缘一圈+嘴角过渡一圈，视现有嘴部凹陷复杂程度可能需要第三圈）。
- **Pole应放在哪里**：环形结构向脸颊过渡处需要放射状辐条，同样会有少量三角面/五边面过渡点，建议放在嘴角外侧不显眼的位置。
- **如何接回IM15K主体**：辐条末端对齐脸颊现有网格线，必要时局部微调脸颊网格走向。现有微笑嘴型、嘴角弧度是重要角色识别特征，不能变。
- **Shrinkwrap目标**：嘴部曲面变化细腻（微笑弧度、嘴角凹陷），建议额外用原始500K高模做一次精细投射校验，不只依赖`2A-base`。
- **对应压力测试**：**没有可用的rig-v01口型/嘴部形变动作数据**（没有Shape Key，`AHAN_Happy`只是身体姿态动作）。建议同样用临时Shape Key做开合测试后删除。
- **FINAL PASS标准**：技术零缺陷 + 环形+辐条结构在临时Shape Key开合测试下无自相交、无非流形、过渡平滑、能自然支撑嘴角上扬/下撇 + 微笑嘴型和嘴角弧度逐像素比对未变。
