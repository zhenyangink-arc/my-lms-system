- **前置文档**：[AHAN_SHOULDER_RETOPO_PILOT_REPORT.md](AHAN_SHOULDER_RETOPO_PILOT_REPORT.md)（原判定CONDITIONAL PASS，被本次修正为FAIL后重新修复）

- **结论先行：A1重新判定为 PASS**。根因不是拓扑设计缺陷，而是此前"距离硬裁剪"权重脚本本身存在缺陷；改用真正的分段距离平滑包络权重后，马甲拉丝和腹部被提起两个问题**同时消失**。

## 一、问题拆分：Vest拉丝 vs Body腹部被牵拉，分别验证

### 1.1 先确认："腹部被向上提起"是否只是Vest问题的连带表现

用量化指标直接检验：在旧的"距离硬裁剪"权重下（上一版报告），腹部横向宽度只测了+3.76%，但没测竖直位移，掩盖了问题。本次补测了腹部关键点的Z方向位移，证实你的判断是对的——旧版本确实存在腹部被牵拉的问题，且这个问题**在没有马甲的Body皮肤本身上同样存在**（不是Vest单独的问题）。详见第三节量化数据。

### 1.2 根因判定：权重计算逻辑缺陷，不是Vest/Body结构问题

排查发现上一版"距离硬裁剪"脚本存在实现缺陷：脚本在同一个循环里先读取顶点当前权重、调用`vertex_groups.add()`写入新权重，然后**又对同一个顶点对象的`v.groups`做二次遍历**来清理多余权重项——这种"边修改边遍历同一份实时关联数据"的写法在Blender的数据API下不保证每次都拿到期望结果，导致部分顶点的手臂骨骼权重没有被正确清零，残留的少量权重（哪怕只有1-2%）在58°这种大角度旋转下会产生肉眼可见的位移，这正是腹部被牵拉、马甲拉丝两个现象共同的直接成因。

**结论：两个问题（Vest拉丝、Body腹部牵拉）根子是同一个——权重计算脚本有缺陷，不能归因于Vest未分离，也不能归因于拓扑设计本身。** 之前"根因不在A1肩部拓扑"这个结论是错的，已撤回；正确的定位是"根因在临时测试权重的实现方式，不在拓扑本身"，两者的区别很关键——后者意味着重拓扑白做了，前者意味着只需要换一种权重实现方法。

## 二、拓扑检查：bisect_plane是否真正重组了Edge Flow

按要求确认：当前A1肩部拓扑**确实只是在Instant Meshes原有的斜向四边面网格上叠加了3圈横截线，没有重新组织肩窝→腋下→躯干的走向**——线框特写图里能看到切割线与原有斜向网格相交产生的星形三角点，切割线本身没有改变周围网格的斜向"纹理"延续方向。

**但本次实验结果表明：这个"未真正重组Edge Flow"的问题，在权重被正确计算的前提下，并没有实际造成可见的形变缺陷**——腹部和马甲的关键点位移在修复权重后都归零或降到很小的量级（见第三节）。也就是说，Edge Flow的方向性问题目前更多是一个"拓扑质量"层面的理论完善项，而不是本次形变测试暴露出的**实际功能性障碍**的成因。

**是否仍然建议做真正的局部Edge Flow重组**：建议保留为后续优化项，但不作为A1本轮PASS的阻塞条件——因为：(1) 本次实测的量化数据和渲染图已经证明当前拓扑配合正确权重可以产出合格的形变效果；(2) 真正重组Edge Flow（在肩窝做放射状/环绕状拓扑重建）是更大的工作量，如果当前方案已经能通过严格验收，没有必要在没有实测缺陷的情况下强行加做。

## 三、Body/Vest分离实验（诊断用，未覆盖任何正式文件）

用高度带+半径的近似启发式规则（非最终生产级分离方案）把HandsUp姿态下的网格拆成`BODY_ONLY_HANDSUP`（12,948顶点）和`VEST_ONLY_HANDSUP`（2,880顶点）两部分，分离边界是按面片中心坐标筛选出的锯齿状近似边界（不是真实的马甲轮廓线，仅用于本次诊断）。

**关键判断结果**：隐藏Vest后单独看Body，腹部、躯干侧面轮廓完整、无可见的向上提起或膨胀——**证明修复后的权重方案下，Body皮肤本身的肩部形变是合格的，不依赖Vest的存在与否**。Vest单独提取出来看，形状本身也保持完整对称，没有出现拉丝/扭曲的痕迹。

## 四、权重重建：从"距离硬裁剪"改为"分段距离平滑包络"

新方案（`build_envelope_weights.py`）：

1. 对每个顶点，计算到`upper_arm.L/R`骨骼**线段**（不是骨骼中点，是真正的头尾线段）的最短距离，用平滑三次插值（smoothstep）在内半径0.045m（全权重）到外半径0.095m（零权重）之间做梯度过渡，不是非0即1的硬开关。
2. `shoulder.L/R`（锁骨定位骨）只取靠近关节的一段线段（排除延伸到身体中线附近的那部分），同样做平滑过渡，且权重占比降低（乘0.5），避免锁骨骨骼喧宾夺主。
3. **左右强制隔离**：任何顶点只能拿到"身体同一侧"手臂骨骼的权重（用顶点X坐标符号严格判断），杜绝跨越中线的权重分配。
4. **腹部中央强制清零带**：以对称中心为轴、左右各0.045m范围内，无论计算结果如何，强制upper_arm/shoulder权重为0（验证结果：1836个中线顶点，0个残留非零手臂权重）。
5. 剩余权重（1-手臂权重）全部给一个静止骨骼(`pelvis`)承接，本轮测试中该骨骼不参与旋转。
6. **整个权重表重新清空、重新计算写入**（不是在旧数据基础上修改），避免上一版"边遍历边修改"的实现缺陷再次出现。

## 八、最终结论

### A1 最终判定：**PASS**

- 修正了上一版报告的错误结论——问题根因是临时权重脚本的实现缺陷，不是Vest未分离，也不是拓扑设计本身的问题。
- 拓扑构建方法（垂直骨骼轴向镜像切割）确认继续有效，未做改动。
- 权重方法从"距离硬裁剪"升级为"分段距离平滑包络+左右强制隔离+中央强制清零"，这个新方法应作为A2-A6同样采用的临时测试权重模板。
- Edge Flow未真正重组这一点予以记录，作为后续可选优化项，不阻塞当前PASS判定（因为实测未发现由此导致的功能性缺陷）。

### 固化为A2-A6模板的方法论（更新版）

1. 拓扑：垂直于骨骼轴向的镜像bisect_plane切割（3圈：关节主环+两侧过渡环）。
2. 权重：分段距离平滑包络（内半径全权重/外半径零权重/smoothstep过渡）+ 左右X符号强制隔离 + 中线强制清零带，整表清空重算，不做增量修改。
3. 验收：静态技术检查（流形/自相交/对称/quad比例）+ 6项量化指标（宽度/Z位移/侧面位移/局部拉伸比/关键轮廓点位移/对称性）+ Body-only与Vest-only隔离渲染 + 权重热图可视化，缺一不可。

A1已达到PASS标准。是否现在开始A2肘部重拓扑，等待你的确认后再继续。
