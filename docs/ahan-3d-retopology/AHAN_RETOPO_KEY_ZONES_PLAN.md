# 阿韩8个动画关键区域重拓扑方案

- **前置文档**：[AHAN_RETOPOLOGY_PLAN.md](AHAN_RETOPOLOGY_PLAN.md)、[AHAN_RIG_V01_MOTION_ANALYSIS.md](AHAN_RIG_V01_MOTION_ANALYSIS.md)、[AHAN_INSTANT_MESHES_TEST_REPORT.md](AHAN_INSTANT_MESHES_TEST_REPORT.md)
- **基础网格**：`/home/yangzhen/Edints/blender/a-han/retopo-v01/base-mesh/AHAN_RetopoBase_IM15K_v01.blend`（15,230顶点/15,606面，95.16%四边面，0非流形，0自相交，单一连通，对称度99.22%）
- **本文档性质**：只是执行方案，尚未开始正式局部重拓扑。
- **核心原则（反复强调）**：**规则四边面 ≠ 动画拓扑合格**。IM_15000打底的全身网格虽然97%是整齐的四边面，但线框检查已经证实这是一个全局统一走向的"网格布"，并没有围绕任何关节自动形成环绕肢体的功能性边线环。下面8个区域的验收依据是"形变方向是否符合关节旋转/表情张合的真实需求"，不是"面是不是四边形"。

---

## 〇、通用工作流程（每个区域都遵循这个流程）

1. 在基础网格上，以该区域的功能坐标为中心，框选一个足够覆盖形变范围的局部面片区域。
2. 删除该区域内的现有面片（保留边界外一圈作为拼接锚点）。
3. 按该区域的Edge Loop设计手工/半手工重建局部拓扑。
4. 用"Bridge Edge Loops"或手动缝合，把新拓扑与周围保留下来的Instant Meshes网格重新连接（连接处允许出现少量三角面/五边面过渡，只要不在正面/常见视角内显眼即可）。
5. 对这个区域的新顶点做Shrinkwrap（最近表面投射），目标是`2A-base/ahan_2A_clean_base.obj`——这是单一连通、无自相交的干净参照面，比直接怼回500K碎片高模更安全；如果Shrinkwrap后仍有细节丢失，允许在确认不引入新自相交的前提下改用原始500K高模做最终一次精细投射。
6. 用同一相机位置渲染修改前后对比图，确认Design Lock六条约束（整体比例/三根头发/五官/拳套手/马甲/左右对称）没有被破坏。
7. 记录该区域用哪个rig-v01动作数据做压力测试（见每个区域末尾）。

## A类：骨骼形变区域

### A1. 肩（Shoulder）—— Z≈0.60m（54%高度），最大约60°

- **当前Instant Meshes拓扑状态**：规则斜向四边面网格穿过肩部区域，没有围绕手臂截面的环形边线；本区域高度（57%）与2B-IM-FIX修复的Spot A（马甲交界处的非流形修复点，57%高度）非常接近，重建时需要留意这个已修复区域的新面片是否需要被这次重建一并覆盖重做。
- **要删除/重建的大致区域**：以肩关节坐标为中心，沿手臂方向覆盖上臂根部到肩窝，沿躯干方向覆盖到马甲肩带覆盖的宽度。
- **Edge Loop应该怎样走**：围绕上臂截面闭合成环（垂直于手臂长轴方向），肩窝处的环形边线需要在腋下位置留出足够的凹陷过渡，不能让边线平直穿过腋下（那样60°抬升时会在腋下产生尖锐折角）。
- **需要几圈主Loop**：3圈——肩关节主环（在0.60m处）+ 上方靠近躯干的过渡环 + 下方靠近上臂的过渡环。
- **过渡区域宽度**：60°是8个区域里最大的转动角，过渡带需要相对宽（建议覆盖上臂直径的0.8-1倍范围），避免抬升到极限角度时形变集中在一条线上产生硬折痕。
- **与周围Quad网格重新连接**：肩部是躯干（大网格密度较低）和上臂（相对独立的圆柱状网格）交汇处，连接处大概率需要2-3个三角面/五边面过渡（这是行业内肩部拓扑的常见做法，不是缺陷），过渡面尽量放在腋下靠后位置（不显眼的角度）。
- **Shrinkwrap回参考表面**：本区域曲面变化复杂（腋下凹陷+肩部凸起+马甲遮盖），建议做完初版拓扑后先用2A-base粗投射一次，再单独针对腋下凹陷区域用原始高模做一次局部精细投射，因为审计报告P1-1提到的腋下接缝问题也在这个区域，顺手确认新拓扑下这个接缝观感有没有变化。
- **避免改变外观**：马甲肩带的可见轮廓线（布料边缘）是外观关键特征，重建边线环时不要移动马甲边缘本身的顶点位置，只调整边缘内侧的走线方式。
- **压力测试动作**：`AHAN_Combing_PreTest`（肩部60°，是全部动作里最大值）+ `AHAN_HandsUp`（双臂同时60°，检查左右对称性）。

### A2. 肘（Elbow）—— Z≈0.46m（42%高度），最大约48°

- **当前状态**：同样是规则斜向网格，无独立中段环。
- **要删除/重建的区域**：以肘关节坐标为中心，上下各覆盖前臂/上臂长度的三分之一左右。
- **Edge Loop走向**：围绕前臂截面闭合成环，肘部内侧（弯曲时挤压的一侧）需要比外侧稍密一些的边线，以便48°弯曲时内侧不产生穿模挤压。
- **主Loop数**：3圈（肘关节主环 + 上下各一圈过渡环）。
- **过渡区域宽度**：中等（48°弯曲量在8个区域里排第二，比肩窄、比腕和膝略窄）。
- **重新连接**：前臂本身是相对简单的圆柱状区域，与周围现有网格密度差异不大，预计不需要额外三角面过渡，直接对齐环数缝合即可。
- **Shrinkwrap**：2A-base即可满足精度需求，不需要额外用高模精细投射。
- **避免改变外观**：拳套手与前臂的整体轮廓（尤其是从侧面看的手臂弧度）不能因为加环而变直或变粗，重建后要用侧视图对比确认。
- **压力测试动作**：`AHAN_Combing_PreTest`（48°，全部动作最大值）+ `AHAN_Thinking`（38°，常规使用范围）。

### A3. 腕（Wrist）—— Z≈0.34m（31%高度），最大约43°（此前方案曾误判为58%，已用rig-v01数据修正）

- **当前状态**：常规网格，无独立环；由于此前方案文档一度把腕部位置猜在58%高度，这次要特别注意确认新建的边线环确实落在31%这个修正后的正确高度，不要沿用旧文档的错误坐标。
- **要删除/重建的区域**：以(±0.335,-0.03,0.34)为中心，覆盖前臂末端到拳套手根部的过渡段。
- **Edge Loop走向**：围绕手腕截面闭合成环。由于拳套手本身不做张合（决策4：保留拳套手、不加真人五指），腕部环只需要支持手腕整体旋转，不需要为手指分支预留任何额外拓扑。
- **主Loop数**：3圈（腕关节主环 + 前臂侧过渡环 + 手掌侧过渡环）。
- **过渡区域宽度**：43°角度不小，且梳头动作里腕部有复合轴旋转（不只是单轴弯曲，还有翻转），过渡带建议比肘部略宽，并确保环形边线在手掌根部足够贴合，避免翻转时手掌与前臂之间出现visible的转折棱角。
- **重新连接**：手掌是一个相对独立的"团子"造型，与前臂网格密度可能不完全匹配，缝合处允许1-2个过渡面。
- **Shrinkwrap**：2A-base即可。
- **避免改变外观**：拳套手三瓣圆润造型的整体轮廓不能变，只在根部（靠近腕关节一侧）调整拓扑。
- **压力测试动作**：`AHAN_Combing_PreTest`（43°，全部动作最大值，且是唯一包含手腕复合翻转的动作）+ `AHAN_Wave_Left/Right`（36°，常规摆手场景）。

### A4. 功能髋（Hip，非解剖学结构）—— Z≈0.28m（25%高度），最大约30°

- **当前状态**：规则网格，此处躯干本身是浑圆连续曲面，没有任何几何提示"髋关节应该在哪"。
- **要删除/重建的区域**：以(±0.11,0.02,0.28)为中心，覆盖大腿根部到躯干下部的过渡带——**这里没有真实的裆部凹陷可以参照，边线环的走线要顺着浑圆躯干本身的自然曲率，不能人为做出解剖学意义上的胯部凹陷**（那样会破坏Design Lock的整体比例，戳穿"没有裆部结构"这个既有造型特征）。
- **Edge Loop走向**：围绕大腿根部截面闭合成环，环的上半部分需要平滑融入浑圆的躯干下部，不能有明显的"分界线"痕迹。
- **主Loop数**：3圈（髋关节功能环 + 躯干侧过渡环 + 大腿侧过渡环）。
- **过渡区域宽度**：30°角度适中，过渡带宽度中等。
- **重新连接**：躯干下部到大腿的曲率变化本身比较平缓，预计不需要额外三角面过渡。
- **Shrinkwrap**：2A-base即可。
- **避免改变外观**：这是全文档里最容易"手滑做过头"的区域——**严禁在这里为了让边线环好看而雕出真实的大腿分叉轮廓**，外部可见的浑圆躯干轮廓线一个顶点都不能动，只调整表面以下的拓扑走线。
- **压力测试动作**：`AHAN_Walk_Test`（30°，全部动作最大值）+ `AHAN_Sit_Test`（25°，同时检查与膝部的联动）。

### A5. 功能膝（Knee）—— Z≈0.18m（16%高度），最大约38°

- **当前状态**：规则网格，无独立环。
- **要删除/重建的区域**：以(±0.145,0,0.18)为中心，覆盖小腿上部到大腿下部的过渡带。
- **Edge Loop走向**：围绕小腿截面闭合成环，考虑到`AHAN_Sit_Test`需要38°弯曲（坐下动作），膝盖内侧（弯曲时受挤压的一侧，即前侧朝向-Y方向）要比外侧略密。
- **主Loop数**：3圈。
- **过渡区域宽度**：38°是下半身两个关节里角度较大的一个，过渡带建议比髋部稍宽。
- **重新连接**：预计不需要额外过渡面，小腿是相对简单的圆柱区域。
- **Shrinkwrap**：2A-base即可。
- **避免改变外观**：短粗的腿部比例和脚掌衔接处的曲线不能变。
- **压力测试动作**：`AHAN_Sit_Test`（38°，全部动作最大值）+ `AHAN_Walk_Test`/`AHAN_Step_Left/Right`（22-25°，常规行走范围）。

### A6. 功能颈（Neck）—— Z≈0.70m（63%高度），最大约36°（此前方案曾误判为86%，已用rig-v01数据修正）

- **当前状态**：常规网格；此前方案文档的线框检查脚本一度用86%这个未经验证的占位高度，这次要确保新环确实建在63%（马甲领口贴合下巴附近），不要沿用旧的86%。
- **要删除/重建的区域**：以(0,0.01,0.70)为中心，覆盖头部底端到马甲领口之间的窄带——rig-v01的动作数据已经证实这里是"头颈作为一个整体转动的单一支点"，不需要在这个支点上下再分层。
- **Edge Loop走向**：围绕颈部截面闭合成一圈完整环，由于马甲领口在视觉上遮住了大部分颈部，这圈环的可见部分不多，但仍需要完整闭合以支撑36°的俯仰+左右转复合运动。
- **主Loop数**：2圈就够（颈部主环 + 头部侧一圈过渡环），因为rig-v01已确认躯干侧不需要独立形变，不用像肩肘那样两侧都建过渡环。
- **过渡区域宽度**：36°角度不算大，过渡带可以相对窄。
- **重新连接**：头部与躯干在这个位置的网格密度可能有差异（头部密度通常更高，因为要覆盖五官细节），缝合处允许1-2个过渡面。
- **Shrinkwrap**：2A-base即可。
- **避免改变外观**：马甲领口的可见轮廓线不能动。
- **压力测试动作**：`AHAN_Head_Left`/`AHAN_Head_Right`（各18°，合计36°是全部头部动作最大值）+ `AHAN_Nod`（20°）+ `AHAN_ShakeHead`（28°），三个动作合起来覆盖了颈部俯仰和左右转两个自由度。

## B类：表情形变区域（不能按普通关节Edge Loop处理）

### B1. 眼周

- **当前Instant Meshes拓扑状态**：规则网格直接穿过眼球/眼眶区域，眼球和周围皮肤是同一套网格里连续的曲面，没有任何独立于皮肤的眼睑结构。
- **要删除/重建的区域**：以双眼中心（参考审计阶段测得的近似坐标，实际以本网格眼球隆起最高点为准做微调）为中心，覆盖整个眼眶凹陷+眼球隆起区域。
- **Edge Loop应该怎么走（不是普通关节环）**：需要围绕眼眶做**同心圆环状拓扑**（俗称"眼部拓扑环"，类似虹膜到眼眶的一圈圈同心边线），而不是让边线直接从旁边平移穿过去。同心环之间用放射状的"辐条"边线连接到外围的常规四边面网格。
- **需要几圈主Loop**：至少3圈同心环——最内圈贴着眼睑边缘（未来眨眼Shape Key的关键控制线）、中间一圈在眼眶转折处、外圈作为向周围网格过渡的缓冲环。
- **过渡区域**：外圈同心环到周围常规网格之间，因为同心环边数和外部方形网格边数通常对不齐，需要若干"辐条转三角"的过渡面（这是脸部拓扑里的标准处理方式，业内叫法通常是"star/pole"过渡点，只要不落在最显眼的瞳孔正前方即可）。
- **与周围Quad网格重新连接**：外圈辐条末端对齐到周围现有的斜向网格线上，必要时局部微调周围1-2圈网格的走向，让辐条能接上而不产生极端拉伸的面。
- **Shrinkwrap回参考表面**：眼球是独立隆起的曲面，投射时要小心不要把同心环"压平"到眼眶皮肤上，建议对眼球部分和眼眶皮肤部分分开做投射校验。
- **如何避免改变阿韩外观**：眼睛的大小、瞳孔位置、高光点位置、上扬的眼型轮廓一个像素都不能变——这一步只是在现有眼睛的表面下方重新组织拓扑，不是重新设计眼睛。
- **压力测试**：**这里没有可用的rig-v01动作数据**——`AHAN_Blink`在rig-v01里明确是"仅作为动作占位，不产生眼睑形变"（状态`FACIAL_RIG_PENDING`），不能拿来当验收依据。建议新拓扑做完后，手动在这个眼周环上试插一个简单的临时Shape Key（睁眼→半闭→全闭三档），验证同心环拓扑在形变时是否平滑、有没有自相交，测试完删除这个临时Shape Key，不算作本阶段正式表情制作。

### B2. 嘴周

- **当前状态**：同眼周，规则网格直接穿过嘴部区域，没有独立的嘴部拓扑结构。
- **要删除/重建的区域**：以嘴部中心（参考审计阶段近似坐标，实际以本网格嘴部凹陷/微笑弧线的实际位置为准）为中心，覆盖整个嘴部及周围脸颊过渡区。
- **Edge Loop应该怎么走**：需要类似眼周的**环形+放射状"orbicularis oris"拓扑**（人脸拓扑里嘴部标准做法：围绕嘴唇开合方向做环形边线，环外用辐条连接到脸颊），**不能只是在嘴的位置简单加一圈线**——一圈孤立的环没办法支撑开合、也没办法支撑说话时嘴角上扬/下撇的AI口型变化。
- **需要几圈主Loop**：至少2-3圈环（贴嘴唇边缘一圈 + 嘴角过渡一圈，视现有嘴部凹陷的复杂程度可能需要第三圈）。
- **过渡区域**：环形结构向脸颊过渡处需要放射状辐条，同样会有少量三角面/五边面过渡点。
- **与周围Quad网格重新连接**：辐条末端对齐脸颊现有网格线，必要时局部微调脸颊网格走向。
- **Shrinkwrap回参考表面**：嘴部曲面变化细腻（微笑弧度、嘴角凹陷），建议这里额外用原始500K高模做一次精细投射校验，不只依赖2A-base。
- **如何避免改变阿韩外观**：现有的微笑嘴型、嘴角弧度是重要的角色识别特征，不能变。
- **压力测试**：同眼周，**rig-v01没有可用的口型/嘴部形变动作数据**（没有Shape Key，`AHAN_Happy`只是身体姿态动作，不涉及嘴部形变），建议同样用临时Shape Key做开合测试后删除，不依赖现有动作验收。

## 五、新增验收项：禁止重现rig-v01旧蒙皮的错误形变（腹部异常拉宽问题）

已确认的历史问题：`rig-v01`预览图 `AHAN_HandsUp`（双臂抬起约58°）中，旧模型的腹部/马甲主体出现了**异常横向拉宽**，这是旧的"世界坐标连续包络"权宜权重方案的错误副作用，**不是正确的角色形变，不能被新模型继承**。

据此，新拓扑设计和后续蒙皮阶段必须满足以下验收标准（本文档先记录，供A1肩部区域拓扑设计和未来蒙皮阶段共同遵守）：

1. 双臂抬起约58-60°时，腹部宽度基本稳定，不能跟随手臂抬升产生横向膨胀。
2. 躯干网格不能因为upper_arm骨骼旋转而产生大范围横向拉伸——这要求A1肩部方案里设计的"肩窝主环"必须足够靠近真实肩关节位置（0.60m），而不是像旧方案那样权重范围蔓延到腹部中央。
3. 马甲主体（前后片、系带）不能被肩部形变大面积拉开变形，马甲的可见轮廓边缘顶点在肩部动作测试中应保持相对稳定。
4. 肩部形变应主要局限在肩窝/腋下附近区域，不应扩散到胸口或腹部。
5. 左右两侧的肩部形变范围不能在腹部中央重叠——即左肩权重和右肩权重的影响范围应该在身体中线附近有清晰分界，不能互相渗透混合。
6. 用`AHAN_HandsUp`和`AHAN_Combing_PreTest`（肩部角度最大的两个动作）做形变测试时，不能出现腋下塌陷、可见裂缝或穿模。

这条验收标准明确了：**rig-v01只继承骨架设计、关节坐标、动作数据这三项，绝不继承旧蒙皮产生的形变结果**——新模型完成蒙皮后，即使用同样的动作数据驱动，形变表现也应该明显优于旧模型的`AHAN_HandsUp`效果。
