# 教学与考核流程

## 当前流程

1. 机构开通学生应用权限并分配负责老师。“学生与教学分配”显示未分配老师、未加入有效计划的人数。
2. 平台维护标准学习计划：课程绑定课时或章节，章节测试绑定真实测试，阶段/期末考试绑定标准考试卷，专项练习和章节巩固绑定已发布内容。
3. 机构选择开课时间与学生名单，发布执行计划。考试须在计划里点击“按计划布置考试”，确认后复用现有考试发布 RPC；实际考试编号记录在计划项目上。
4. 学生周表与机构执行明细共用数据库完成事实。老师可以按学生/安排搜索，并筛选逾期、待批改、待完善等状态。
5. 平台在“结课政策与统计”保存、核对和发布政策；机构在“结课资格”查看缺口、补考及发证。

## 完成口径

| 内容 | 完成依据 |
| --- | --- |
| 课时 | `lesson_progress.status = completed` |
| 教材章节 | 与章节测试关联的 `course_ebook_progress.completed_at` |
| 章节测试 | 当前学生有通过记录 |
| 章节巩固 | 绑定版本的巩固进度存在 `completed_at`，不等同于掌握度达标 |
| 专项练习 | 对应练习在该安排开始后有已完成会话 |
| 已布置考试 | 最新提交成绩已公开；不等同于及格，结课资格继续检查分数 |
| 旧手工安排、复习说明 | 不推断完成率，显示待完善；新考试/练习必须绑定真实来源才能发布 |

完成和待批改状态优先于时间判定，避免已完成或已提交任务变成逾期。没有数据与明确未完成分开处理。

## 边界

- 平台查看机构汇总，不为查看页面创建任何真实用户的认证会话。
- 执行事实 RPC 限定当前机构、有效学籍及当前应用老师负责关系，只返回完成状态，不返回作答正文。
- 考试布置锁定计划并幂等执行，时间与名单来自计划。已有考试的计划不接受新增学生；新增学生需独立计划。取消计划前需先结束已布置考试，避免隐藏计划后考试继续运行。
- 已采用的停用模板仍可由被授权机构工作人员读取。
- 政策发布原子替换课程旧默认政策，失败时全部回滚；已颁发证书保留原快照。
- 政策界面仅开放当前计算引擎实际支持的数值阈值和作业要求；教材完整性、阶段及期中/期末成绩公开、认证主观题批改显示为固定规则。
- 巩固进度目前用于执行追踪，未新增强制巩固达标的发证政策。原结课计算引擎仍按教材与考核要求计算。

## 数据库与后台服务上线

先确认目标数据库已应用现有学习计划及结课政策迁移，再按顺序应用：

1. `supabase/migrations/202609080004_teaching_operations.sql`
2. `supabase/migrations/202609080005_completion_policy_management.sql`

不要直接推送工作区全部未发布迁移：其中可能包含其他任务的改动。完成数据库迁移后再发布对应应用代码。

刷新服务使用服务端现有环境变量，不生成登录令牌，也不把凭据写到进程配置中：

```sh
# 单次处理，适合外部调度器
node --env-file=.env.local scripts/process-course-completion-refresh.mjs

# 或使用 PM2 每 30 秒处理一个批次
pm2 start ecosystem.completion-worker.cjs
```

单批处理最多 10 个队列任务；队列任务本身可以覆盖多个学生。失败记录可由平台负责人在页面重新排队。手动执行按钮可处理一批任务，但不能代替持续运行的后台服务。处理日志只含汇总数量，不打印学生数据或数据库错误正文。

## 验证

- `npm run typecheck`
- 相关学习计划、结课、补考、管理路由回归测试。
- `tests/curriculum-execution.test.mjs`：时间与完成状态优先级、实际考试时间、政策表单校验。
- `tests/teaching-operations-db.test.mjs`、`tests/completion-policy-management-db.test.mjs`：PGlite 合成数据的数据库行为与授权测试。设置 `LMS_PGLITE_MODULE` 指向 PGlite 模块运行。
- `node scripts/verify-teaching-operations-ui.mjs`：隔离组件的搜索、筛选、跳转、确认、键盘提示和 390px 手机布局，使用现有 `.next/static/chunks` 样式。
- 本地 Supabase 对前置学习计划迁移和本次两份迁移进行同一事务内编译检查，完成后回滚。

上述检查不证明线上真实数据已验收，也不会自动应用远程迁移或启用 PM2 服务。
