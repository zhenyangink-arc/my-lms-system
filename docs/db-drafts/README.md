## 预演中的发现

- **原触发器的角色漏洞**：教职人员判断读 `profiles.role`，而课时进度的写入规则（RLS）要求机构成员角色为学生。资料角色为教职人员、成员角色为学生的普通会员可绕过档位写入正式课时进度（测试第 10 条复现）。D2 改用成员角色后修复。
- **老师预览课时被拒的担忧不成立**：写入规则只允许成员角色为学生的账号写入课时进度，教职人员本来就不会走到触发器的档位判断。
- **代码侧口径待核对**：课时页（黄区）用资料中的会员档位（`profile.membership_tier`）判断，数据库用成员关系中的档位，两者依赖同步触发器保持一致。课时页插槽阶段改造“完整课程访问”时一并统一。
