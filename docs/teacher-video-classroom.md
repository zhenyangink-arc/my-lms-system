# 教师视频课堂接入

视频由 HeyGen Creator 制作并导出，UPLY 负责教学顺序、教材操作、提问和反馈。第一版不调用 HeyGen API，也不需要 HeyGen 密钥。

## 上传与绑定

1. 导出 MP4，推荐 H.264 视频与 AAC 音频。画面中保留完整老师和背景；需要同步字幕时可先在成片中烧录字幕。
2. 上传到现有 Cloudflare R2 桶中的 `teacher-video/` 目录，例如 `teacher-video/chapter-01/opening-v1.mp4`。
3. 打开教学脚本草稿，选择“老师讲解”，将呈现方式设为“教师视频课堂”。一个讲解片段可以包含几句话；台词文本应与视频内容一致。
4. 在片段卡片中选择“从视频库选择”，检查并绑定文件。也支持填写完整 R2 对象路径。视频播放时使用大画面；结束后按任务切换到学生互动。
5. 在“老师发起”中绑定操作要求、提问视频。若这些话已经包含在讲解视频中，勾选相应选项；进入学生回应时不会重复播放。
6. 在“学生回应”中设置操作目标或答案。在“老师反馈”中分别绑定操作完成、答对、答错视频；未绑定反馈视频时显示现有反馈文字。
7. 保存草稿，预览完整流程，检查后发布。现有完整流程预览入口仍只支持第一章。

R2 已有上传脚本可用：

```sh
node --env-file=.env.local scripts/publish-r2-object.mjs /absolute/path/opening.mp4 teacher-video/chapter-01/opening-v1.mp4 video/mp4
```

视频文件路径是稳定素材标识。更新成片应使用新版本文件名，并重新绑定，避免覆盖正在使用的文件。解除绑定不会删除 R2 文件。

## 保存和播放

- 素材绑定保存在节点 `configuration.teacherVideo` 中，随现有草稿复制、发布和归档保存，无需新增数据库表。
- `explanations` 与逐段台词同步保存；删除片段时同时删除其绑定。编辑台词后，旧视频标记为需要核对，发布前会拦截。
- `configuration.scriptSegments["zh-CN"]` 保存明确的编辑片段边界。段内空行保留，不拆成新视频；旧脚本没有此字段时仍按原来的空行规则读取。
- 当前视频按中文备课片段绑定；切换界面语言不改变成片语言或片段编号。需要韩语成片时须另行制作绑定，不能把界面语言切换当作视频翻译。
- 节点与私有答案通过 `save_teaching_script_node_atomic` 一次事务保存；任一步失败全部回滚，过期页面不能覆盖更新后的内容。
- 发布先取得节点和答案快照，检查实际启用的视频，再通过 `publish_teaching_script_checked` 锁定并比对快照。期间有修改就中止发布；未启用的旧视频仍保留绑定，但不参与媒体存在性检查。
- `turns` 分别保存操作要求、提问、操作完成反馈、正确反馈、错误反馈。运行时按实际教学阶段和服务器判定的结果选择视频。
- 教师视频使用 `/api/learning-agent/teacher-video` 私有媒体代理，检查登录状态和韩语课程权限，支持 Range 请求。R2 签名链接不交给浏览器。
- 视频模式使用成片音轨，不播放原人物或独立朗读。补充提问与缺省反馈使用文字。
- 视频课堂不显示 PPT 或黑板，也不提供独立画面编辑入口。原有场景数据保留，视频模式不调用；学生操作所需的教材内容在回应阶段出现。
- 自动播放若被浏览器拦截，显示播放按钮。加载失败时可以重试或阅读文字后继续；学生回应会等到视频结束或明确选择文字方式后开放。
- 讲解可连续播放，学生任务和问题会等待学生。暂停、退出或切换模块时停止当前视频。同一浏览器标签页内记录片段播放位置；课程节点进度继续使用已有服务端教学状态。

## 当前边界

桌面课堂按教学阶段切换：讲解与反馈使用视频主画面；学生操作时在教材上方显示任务和定位入口；答题时使用主区域内的题卡，保留侧边视频，不使用遮罩弹窗。课堂控制集中在视频下方，课程目录从顶部菜单打开，视频反馈台词默认收起。旧人物模式保留原有弹窗交互。

- 素材库来自 R2 目录，展示文件名、大小和节点引用；时长在视频预览加载后显示。第一版未建立独立的可编辑素材元数据表。
- 预览封面由浏览器的视频首帧提供，字幕可烧录在成片中；后台台词是完整文本，尚无逐字时间轴编辑器。
- 本地播放位置不是跨设备的秒级同步。现有课程节点进度仍由后端管理。
- 保留已有已发布脚本的原有模式；视频切换通过草稿保存和发布生效。
