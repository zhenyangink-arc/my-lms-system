# 课程内容工作流程

四个管理入口共享 `chapter` 查询参数，值为具体教材版本中的章节 ID。课程结构定位所属课时；教材与脚本不会按章节编号猜测其他版本。脚本只使用其工作台当前支持的教材版本，不匹配时提示重新选择。

## 教材与练习

- 教材原文由教材制作维护；历史导入词汇、语法仍是独立副本。
- 在练习工具选择章节后，核对完整内容并确认关联。关联保存版本与内容快照，不会更新独立词库。
- 教材原地修改后显示待复核；复核确认前继续使用上次快照。更新和停用使用 revision 比较，防止覆盖他人的操作。
- 教材下架、版本归档或引用停用后，学生读取不再返回该引用。
- 新版专项训练在原有章节开放检查后，以所属课时和关联章节测试匹配材料。词汇显示词卡复习，语法显示文字材料；不自动生成正式题目或计分。缺少匹配关系时不猜测章节。
- 本章准备情况显示引用状态并链接到练习工具。新增发布检查读取正式脚本、复核状态、视频文件和所选学生的真实开放条件；不登录该学生账号。视频文件读取成功不等于浏览器解码和画面验收通过。

## 最终收尾（2026-09-08）

已应用 `202609080003_teaching_script_source_reviews.sql`，远端迁移记录已同步。

- 脚本复核绑定教材模块、内容节点、活动、答案与解析以及脚本内容。教材或脚本变动后显示待复核。
- 发布状态变更由数据库触发器复查来源快照与脚本令牌；过期复核不能发布。已有已发布脚本不自动下架。

正常登录后的验收顺序：

1. 教材制作选择章节和版本，切换脚本、练习工具确认定位保留。
2. 在脚本中保存编辑，读取教材复核内容，对照后确认复核；教材或脚本再次变化后检查待复核提示。
3. 在练习工具对照快照，确认引用或更新，再到已解锁章节查看词卡和语法材料。
4. 在脚本页运行发布检查，明确选择一名学生，处理未满足项，再用脚本预览检查视频画面和播放效果。

上述确认操作由管理员正常登录后执行，不自动替管理员认可教材内容、发布脚本或建立练习引用。
