# Packet: Round1/Packet1 — 期中考试蓝图与题目来源冻结

## 背景
仓库根目录存在方案文档 `docs/korean-level-one-midterm-final-certification-roadmap.md`。
开始前请完整阅读该文档，重点是第6节（期中考试设计）、第8节（试卷发布质量门槛）、
第22节 Round1/Packet1 的任务与验收描述。本 Packet 严格按该文档执行，不得扩大范围。

## 目标
冻结韩国语一级期中考试（覆盖第1—8章）的内容合同：能力覆盖矩阵、六项能力分值、
候选题目的章节/知识点/能力标注、听力临时音频状态、口语写作量规。
本 Packet 只产出「可审核的内容合同」文档，不写入数据库草稿表、不新增证书相关表、
不修改学生端页面、不改动现有提交判分状态机。

## 范围与非目标
- 允许：探索仓库中韩国语一级第1—16章智能教材内容源（词汇、语法、听说读写活动）、
  现有章节考试/阶段考试草稿的数据结构与存放位置，以此作为期中卷选题的权威来源。
- 允许：新增一份结构化内容合同文档（建议 Markdown 或 JSON，你可自行决定格式和路径，
  放在合理位置，例如 `docs/exams/` 或与现有考试草稿数据同目录，需在报告中说明选择理由）。
- 不允许：创建/修改 `assessment_papers`、`assessment_paper_questions` 或任何数据库迁移文件。
- 不允许：修改任何学生端/教师端/管理端页面代码。
- 不允许：修改现有提交、判分、成绩发布相关代码。

## 冻结决策（来自方案文档，不可更改）
- 母卷代码：`EX-K1-MID-V1`。
- 考试时长75分钟，满分100分。
- 六项能力与分值：词汇15、语法20、听力15、口语15、阅读20、写作15。
- 覆盖章节：第1—8章，至少覆盖6个不同章节。
- 每道题必须标记能力、来源章节、知识点。
- 语法题需包含跨章节辨析；阅读听力使用新的综合语境；口语写作不得复制教材示范答案。
- 临时音频必须标记 `temporary`，不得标记为 `formal`。

## 验收标准
1. 内容合同文档存在，且明确列出：覆盖章节清单（≥6章）、六项能力清单与分值（合计100）、
   每道候选题的章节来源/知识点/能力标签、听力音频状态标注方式、口语写作量规草案。
2. 文档中的分值合计严格等于100。
3. 文档不引用不存在的教材章节或知识点（需与仓库现有教材数据源交叉核对）。
4. 未产生任何数据库迁移文件、未修改任何页面组件、未修改判分/提交状态机代码
   （用 `git status` / `git diff` 自证并在报告中列出）。
5. 运行仓库现有的类型检查/lint（如适用）确认没有因新增文档相关代码而破坏构建；
   若本 Packet 未新增任何代码文件（纯文档），可说明無需运行构建，但需运行
   `git status --porcelain` 证明改动范围可控。
