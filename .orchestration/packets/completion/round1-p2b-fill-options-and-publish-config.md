# Packet: Round1/Packet2b — 补齐选择题干扰项与发布配置（Packet2 遗留缺口修复）

## 背景
Round1/Packet2 已完成 `EX-K1-MID-V1` 草稿录入，但报告了3个使草稿仍不可发布的缺口：
1. 33道客观题（V/G/L/R）只冻结了标准答案，没有干扰选项（选择题缺少错误选项）。
2. 未设置及格分（passing score / 及格线字段）。
3. 重复提交次数等规则未确认。
5道听力题维持 `temporary` 音频状态属于预期设计，不是缺口，不要改动。

内容合同：`docs/exams/korean-level-one-midterm-v1-content-contract.md`；
迁移：`supabase/migrations/202608190023_seed_korean_level_one_midterm_v1_draft.sql`。

## 目标
1. 为33道客观题各生成3个合理的干扰选项（每题共4个选项，1个正确），干扰项须与该题的
   语法点/词汇/知识点相关但明确错误，不得出现两个可判为正确的选项，不得重复。
2. 及格线、最大提交次数等发布配置：**必须复用仓库中现有韩国语一级章节考试或阶段考试草稿
   已经采用的同类配置数值/策略**，保持产品口径一致，不要自行发明新数值。若历史草稿的配置
   本身不统一，选用阶段考试（4套，覆盖范围与期中卷性质最接近）的配置为准，并在报告中说明
   具体参照的是哪一份草稿及对应数值。
3. 将上述内容写入新的迁移，更新草稿数据（草稿仍保持 draft 不可见，本 Packet 不发布）。
4. 更新 `docs/exams/korean-level-one-midterm-v1-content-contract.md`，补入干扰选项和发布配置，
   使合同与数据库草稿保持一致（合同是唯一权威来源，不能只改数据库不改文档）。

## 非目标
- 不接入发布按钮、不做机构布置（Round1/Packet3 范围）。
- 不修改已冻结的正确答案、分值、题干、材料、量规。
- 不修改历史迁移 `202608190023`，新增迁移文件补充即可。

## 验收标准
1. 33道客观题每题4个选项、恰好1个正确，干扰项与知识点相关且无歧义。
2. 及格线与提交次数配置来自仓库真实存在的既有韩国语草稿配置，报告中给出参照来源和具体数值。
3. 内容合同文档与数据库草稿逐项一致（可用查询比对）。
4. 质检逻辑对更新后的草稿重新运行，此前报告的3项缺口全部消失；草稿依然是 draft，
   对学生/机构不可见。
5. `git status` 范围仅限新迁移、合同文档；无关文件未改动。
6. 类型检查、lint、既有测试（含 Packet2 新增的 `tests/korean-midterm-paper.test.mjs`）通过。

## 交付形式（报告）
- 改动文件列表。
- 每条验收标准 PASS/FAIL/BLOCKED。
- 验证命令、退出码、关键输出（含质检从"3项缺口"到"通过"的前后对比）。
- 参照的既有配置来源说明、已知风险。
